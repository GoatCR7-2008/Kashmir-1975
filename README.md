# APS4 - Projeto em Python

Este projeto utiliza uma interface gráfica criada com `customtkinter` e manipulação de planilhas/dados com Python.

## 🚀 Como executar o projeto

### 1. Pré-requisitos
Certifique-se de ter o Python instalado na sua máquina.

### 2. Instalar as dependências
Abra o terminal na pasta do projeto e execute o comando abaixo para instalar todas as bibliotecas necessárias (`customtkinter`, `pandas`, `openpyxl`, `matplotlib`, etc.):

pip install -r requirements.txt

### 3. Rodar a aplicação
Após instalar as dependências, rode o arquivo principal:

python app.py
